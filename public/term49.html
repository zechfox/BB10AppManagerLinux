Original BerryFarm Term49 uses .term49rc; BerryCore's Term49 package is Term48-based and uses .term48rc. The Classic companion (.term49cjkrc) takes priority when auto-detect is on and it is installed. Auto-detect checks the app sandbox and existing files.

Theme

Term49 exposes default text and background colors. Its ANSI palette is compiled in, so colored output from ls, git and editors keeps the same accents.

blackberry@bb10:~$ ls
Documents  notes.txt  term49-web
blackberry@bb10:~$ echo "Hello BB10"
Hello BB10
blackberry@bb10:~ _

Font

Use a monospace TrueType or OpenType font available on the device. Relative paths are resolved from Term49's home.

Default: /usr/fonts/font_repository/monotype/andalemo.ttf (Andale Mono).

Set 0 to let Term49 auto-detect a size from the screen width. Other sizes are used directly.

Behavior

The remaining useful options from the active Term49 config.

Metamode lives in the top-left corner. Tap it, then use h/j/k/l for arrows, c for Ctrl and v to paste.

Classic companion

Build and manage Term49-Classic on the device: 4,096-line scrollback and a terminal-local Pinyin IME, attached to the signed Term49 window. Everything compiles on-device with BerryCore's GCC.

Write configuration

Saving keeps unrelated settings such as custom metamode keys and backs up the previous file as .term49rc.bak or .term48rc.bak.

Term49 reads this file at launch. Close and reopen Term49 after saving to apply the new theme and font.

Advanced: edit the raw config

libconfig syntax. A malformed file is ignored by Term49, which then starts with defaults.
