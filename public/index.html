    Before you start

    1. Enable Development Mode in the device's Security settings.
    2. The device web service uses HTTPS with a self-signed certificate. The local proxy accepts it for you.
    3. An app that is incompatible with BB10 / PlayBook OS will not run regardless of how it was installed.
