    Before you start

    1. 1
      Enable Development Mode

      Turn it on in the device's Security settings.

    2. 2
      Accept the certificate

      The device serves HTTPS with a self-signed certificate. The local proxy accepts it for you.

    3. 3
      Match the OS

      Apps that are incompatible with BB10 / PlayBook OS will not run, however they were installed.

    Connection tips

    • Use the device's Wi-Fi IPv4 address for wireless access.
    • USB connections usually appear as 169.254.x.x.
    • Keep this Node process running while you manage the device.
