Behavior

These settings go into a managed block at the end of ~/.tmux.conf; other lines are preserved.

On Term49, tap the top-left corner or hold Space for metamode: c acts as Ctrl, so c then the prefix key works on a touchscreen.

Scrolling on a touchscreen

Term49 forwards taps and drags but not wheel events, so swipes and the trackpad cannot scroll tmux. Use copy mode with keys instead.

  1. Tap the top-left corner in Term49 (or hold Space) to enter metamode.
  2. Press c for Ctrl, then the prefix key, then [ to enter copy mode.
  3. Use j/k or the arrow keys on the physical or on-screen keyboard to scroll. Press q to leave copy mode.

In vi copy-mode, h/j/k/l move like arrows. The pane status shows [0/0] while copy mode is active.

Write configuration

Saving writes ~/.tmux.conf and backs up the previous file as .tmux.conf.bak.

tmux reads this file when the server starts. Use Apply to running tmux above to reload an active server.

Advanced: edit the raw config

A managed block at the end is regenerated from the form. Everything outside it is preserved.
